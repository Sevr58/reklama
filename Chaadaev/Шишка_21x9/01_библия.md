## 1. Концепт

**Логлайн.** Девочка находит у леса идеальную шишку и несёт её через весь двор, чтобы сделать нос снеговику у своего подъезда. Её путь от леса до двери — экскурсия по жизни ЖК.

| | |
|---|---|
| Драматический вопрос | Куда она так бежит с этой шишкой? |
| Хочет | Доделать снеговика — у него нет носа |
| Нуждается | Чтобы мама увидела её работу (финал у окна) |
| Единственная демонстрация | Шишка становится носом снеговика |
| Дуга | Находка в лесу → гордость перед мамой |
| Финальный образ | Мама и дочь у окна, внизу снеговик с носом-шишкой; камера уходит вверх — лес до горизонта |
| Тема (не произносится) | Лес и дом — одно место. От опушки до подъезда — один короткий детский забег |
| Стиль | Тёплое семейное кино в холодной зиме; натурализм, без рекламного глянца |

**Что изменилось против версии 7.2:**
- убран кофе и титр «Мама — из центра»;
- мама не «вернулась», а ждёт дома — сцена в прихожей сокращена до встречи;
- добавлено **лобби** (ресепшен с вывеской «ЧААДАЕВ») — бренд в кадре без логотипа в посте;
- маршрут девочки идёт строго по локациям из рендеров.

### Тесты

| Тест | Вердикт |
|---|---|
| Хребет | ✅ «Хочет сделать нос снеговику, но снеговик далеко — через весь двор» |
| «Но / поэтому» | ⚠️ Середина (площадка, воркаут, пергола) — это «и потом». Лечение: в каждой локации девочку что-то **на долю секунды тормозит**, и она бежит дальше (горка зовёт — не останавливается; парень подмигивает — она машет шишкой; снегири — замирает, но вспоминает про нос). Тогда каждая локация = «но она не останавливается, потому что несёт нос» |
| Одна демонстрация | ✅ шишка → нос |
| Контракт крючка | ✅ 0–2 с: шишка падает в снег крупно — обещание «эта вещь важна». Финал выполняет: шишка стала носом |
| Топор масштаба | ✂️ Отрезано: кофе-метафора (второй фильм про маму из центра) |
| Банальность | Средне. «Ребёнок бежит по ЖК» — частый ход. Спасает цель-предмет и окно в финале |

## 2. Бит-шит (20 с)

| Тайм | Видимое действие | Сдвиг | Сетап / пэйофф | Внимание держит |
|---|---|---|---|---|
| 0–2 | Шишка падает с сосны в свежий снег, снежная пыль. Красная варежка выхватывает её | ноль → находка (+) | **С1:** форма шишки · **С2:** красные варежки | Макро, рапид, тишина |
| 2–4 | **Поэтому** девочка вскакивает и бежит от опушки к домам. За ней по лыжне скользит лыжник | + движение | | Масштаб: лес → дома в одном кадре |
| 4–6 | **Но** у горки дети катятся на ледянках и зовут. Она не останавливается — машет на бегу | соблазн → цель (+) | | Детский смех, проводка |
| 6–8 | Воркаут: парень подтягивается, пар изо рта, подмигивает. Она поднимает шишку как трофей | + гордость | | Звон турника |
| 8–10 | Пергола: дедушка с бабушкой, снегири у кормушки. Девочка замирает на полшага… и бежит дальше | пауза → цель (+) | Снегири красные = рифма с **С2** | Единственная пауза перед финишем |
| 10–12,5 | Вход: снеговик без носа. Она встаёт на цыпочки, втыкает шишку. Отходит на шаг | **ПИК** | **П1:** шишка = нос | Крупный план носа |
| 12,5–14 | Лобби с вывеской «ЧААДАЕВ»: она пробегает к лифтам, снег сыплется с шапки | + дом | | Тёплый свет после холода |
| 14–16,5 | Квартира: мама на коленях снимает с неё шапку. Девочка тянет маму к окну, тычет пальцем вниз | связь (+) | **С3:** жест вниз | Поведение мамы: смех глазами |
| 16,5–18,5 | Через стекло — снеговик с носом-шишкой у подъезда; камера уходит вверх над двором — лес до горизонта | **финальный образ** | **П3:** взгляд вниз → кран вверх | Музыка раскрывается |
| 18,5–20 | Пэкшот | CTA | | Финальный аккорд |

**Реестр сетапов:** С1 форма шишки → П1 нос · С2 красные варежки → снегири, узнаваемость героини · С3 жест вниз → кран.
**Пик:** нос снеговику (10–12,5). **Конец:** лес до горизонта. Оба построены.

## 4. Режиссёрская книга (повторяется дословно во всех промтах)

1. **Тон:** тёплое семейное кино, натурализм, без рекламного глянца. Камера смотрит на уровне глаз ребёнка.
2. **Палитра:** холодный сине-белый снег, тёмно-зелёные сосны, **один акцент** — ягодно-бордовые шапка и варежки девочки (~#6B1F2D по утверждённому листу; снегири как рифма). Интерьер — тёплый янтарь. Цветовой сценарий: холодный старт → тёплый финал.
3. **Свет (обновлено 2026-11-20, решение Евгения 2026-11-19):** солнечный зимний день, голубое небо, низкое солнце слева сверху, длинные голубые тени; **без снегопада** — вместо него искрящаяся морозная пыль в лучах. Интерьер: дневной свет из окна плюс тёплые бра.
4. **Направление на экране:** девочка всегда бежит **слева направо** (от леса к дому). Не нарушать.
5. **Камера:** одно движение на кадр — проводка сбоку, статика, медленный наезд. Финал — единственный кран вверх.
6. **Оптика:** 21:9 анаморф, 35–50 мм на проводках, 85–100 мм макро на шишке и носе, малая ГРИП на крупных.
7. **Ритм:** короткие кадры по 2 с в середине, пауза у снегирей, самый длинный кадр — кран.
8. **Звук (обновлено 2026-11-20, решение Евгения):** музыка звучит **весь ролик** — лёгкая, пианино и/или струнные, подпрыгивающий ритм бега (~112–118 BPM); под ней — хруст снега и дыхание. Драматургия музыки: лес и бег — пиццикато + пианино; снегири — короткая остановка на задержанной ноте; нос — акцент; дом/окно — тёплый разлив смычковых; кран и пэкшот — финальный аккорд. Без бубенцов и «рождественского» звучания. Промты Suno — раздел «Музыка (Suno)» ниже.

**Look для промтов:** photorealistic, Kodak Vision3 250D, мелкое зерно, мягкая халация на снегу, anamorphic 2.39:1.
