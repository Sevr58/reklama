## МЕТОД ТОЧНОСТИ (утверждается, 2026-11-19)

1. **Основа — сам рендер, обрезанный в 21:9 без генерации** (`референсы/локации_21x9/`). Геометрия = 100% рендер.
2. **Править только инпейнтом/редактированием, не генерировать заново:** убрать людей (маска → «empty snow»), зимовать летние рендеры командой «change only the season, keep every building, object and position exactly».
3. **В Seedance плейт идёт первым кадром (start frame), а не только референсом.** Камера — одно короткое движение, герои входят в кадр. Значит, один клип = одна локация (8 клипов вместо 3–4).
4. Вертикальные рендеры (044, 046) — расширять бока (Expand) или заменить горизонтальными. Решение за Евгением.

Ниже — исходные промты для генерации «с нуля». Используем их только если инпейнт/редактирование не справились.

## Как пользоваться

Для каждой локации делаем **«плейт»** — пустой зимний кадр 21:9 без людей, по рендеру клиента. Генератор картинок в Higgsfield (Nano Banana Pro), рендер прикладываем референсом. Потом плейт идёт в Seedance как `@loc_…`, а герои — своими листами.

**Почему плейты, а не сами рендеры:** рендеры летние, разного формата и света. Seedance с летним рендером оставит зелень, с разным светом — склейка «прыгнет». Плейт фиксирует одну зиму, один свет и формат 21:9.

### Единые правила для всех плейтов (повторяются в каждом промте)

- **Архитектура — строго как на рендере:** фасады белые и серые панели, первый этаж из тёмного графитового кирпича, чёрные рамы, те же МАФы, фонари, лавки.
- **Зима одна и та же:** свежий пушистый снег, деревья в снегу, лёгкий снегопад, зимний день, мягкая яркая облачность, низкое солнце слева сзади сквозь дымку. Холодный сине-белый, тёплые окна.
- **Камера:** на высоте глаз ребёнка (~1,1 м), если не сказано иное. Формат 21:9.
- **Пусто:** без людей, без машин в кадре двора, без текста.
- Без новогодней атрибутики.

**Общий негатив для плейтов:**
```
people, person, crowd, cars in courtyard, summer, green grass, green leaves, autumn leaves, melting snow, slush, puddles, night, dusk, sunset orange sky, Christmas decorations, garlands, Christmas tree with toys, New Year, Santa, text, signs with words, logos, watermark, distorted architecture, curved walls, different building, different facade colours, fisheye, CGI look, 3d render look, cartoon, illustration
```
